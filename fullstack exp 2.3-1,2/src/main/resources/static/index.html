              🏛️
              Security Architecture Flow
            

          

          

            Stateless Request Pipeline & Role-Based Access Control filter execution:
          


          

            
1. Client Request

              └→ HTTP Header: Authorization: Bearer <JWT>


            
2. JwtAuthFilter

              └→ Reads Bearer token

              └→ Jwts.parser().verifyWith(secretKey).build().parseSignedClaims()

              └→ Extracts subject & role claim

              └→ Sets SecurityContextHolder.setAuthentication(...)


            
3. SecurityFilterChain Authorization

              └→ /api/admin/** → requires ROLE_ADMIN

              └→ /api/manager/** → requires ROLE_MANAGER or ROLE_ADMIN

              └→ /api/reports/finance → @PreAuthorize check

              └→ 401 on expired/tampered JWT, 403 on role mismatch.


            
4. AES-256-GCM Secure Storage

              └→ Credential secrets encrypted before database insert

              └→ Fresh 12-byte random IV + 128-bit authentication tag
